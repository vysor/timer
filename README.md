# Terminal Timer ⏱️

A beautiful, simple focus timer and stopwatch for your terminal with ASCII art display.

## Features

- 🎨 **ASCII Art Display** - Large, clear time display using ASCII art
- ⏰ **Focus Timer** - Pomodoro-style focus sessions (25min, 45min, or custom)
- ⏱️ **Stopwatch** - Track elapsed time
- 📊 **Progress Bar** - Visual progress indicator for focus sessions
- 🎯 **Simple Interface** - Easy-to-use menu system

## Usage

Run the timer:
```bash
python3 timer.py
```

Choose from:
1. Focus Timer (25 minutes) - Perfect for Pomodoro technique
2. Focus Timer (45 minutes) - Extended focus session
3. Custom Focus Timer - Set your own duration
4. Stopwatch - Track elapsed time
5. Exit

## Requirements

- Python 3.x
- Works on Linux, macOS, and Windows
